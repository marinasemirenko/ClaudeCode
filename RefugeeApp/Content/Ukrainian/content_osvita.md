## 📌 Школа для дітей

**Обов'язкова освіта:** з 4 до 18 років (leerplichtig).
Якщо твоїй дитині 4+ роки — вона зобов'язана ходити до школи. Це закон.

**Типи шкіл:**
| Вік | Тип |
|---|---|
| 4–12 років | Basisschool (початкова) |
| 12–18 років | Middelbare school (середня) |
| 12–18 (іноземці) | ISK — International Schakelklas (клас адаптації) |

**ISK — International Schakelklas:**
Спеціальний клас для дітей, що не говорять нідерландською. Там вчать мову та адаптують до нідерландської системи освіти. Більшість шкіл мають ISK або направляють туди.

**Як записати дитину:**
1. Звернись до місцевої школи або до gemeente
2. Принеси документи дитини (свідоцтво про народження, паспорт)
3. Школа зобов'язана прийняти — відмова незаконна

## 📌 Курси нідерландської мови (NT2)

**NT2 = Nederlands als Tweede Taal** (нідерландська як друга мова)

**Безкоштовні варіанти:**
- Через gemeente — уточни у соціальному відділі
- VluchtelingenWerk — організовує курси для біженців
- Stichting Taalstap — безкоштовні заняття у багатьох містах
- Taalcoach — волонтерська програма: нідерланд. навчає тебе особисто

**Платні (але якісніші):**
- ROC (Regionaal Opleidingscentrum) — офіційні курси NT2
- Ціна: ~€800–2000, але є субсидії

**Рівні NT2:**
- A1 → A2 → B1 → B2 → C1
- Для громадянства потрібен мінімум B1

## 📌 Inburgering — Інтеграційний іспит

**Що це:**
Обов'язкова програма інтеграції для деяких категорій іноземців. Включає:
- Іспит з нідерландської мови (NT2 рівень B1)
- Знання нідерландського суспільства (KNS)
- Знання нідерландського ринку праці (ONA)

**Чи обов'язково для українців?**
Поки що — НЕ обов'язково для всіх. Але рекомендовано. Уточни свій статус на inburgering.nl.

**Де підготуватися:**
🔗 https://www.inburgering.nl
🔗 https://www.oefenen.nl (безкоштовні вправи)

## 📌 Вища освіта — HBO та Університет

**Для вступу потрібно:**
- Диплом або атестат з України (оригінал + переклад)
- Визнання диплому через Nuffic або IDW
- Достатній рівень нідерландської або англійської мови
- Апліка через Studielink (для нідерландськомовних програм)

**Де навчатись англійською:**
Більшість HBO та університетів мають програми англійською. Шукай на studyfinder.nl.

**Вартість:**
- EU-статус: ~€2500/рік (базова ставка)
- Non-EU: €6000–15000/рік
- З тимчасовим захистом: зазвичай EU-ставка — уточнюй в університеті

**Стипендії та гранти:**
- UAF (Stichting voor Vluchteling-Studenten) — допомога біженцям у вступі та фінансуванні
  🔗 https://www.uaf.nl
- Holland Scholarship — для міжнародних студентів
- Erasmus+ — для деяких програм

## 📌 Визнання українського диплому

**Два шляхи:**
1. **Nuffic** — офіційна оцінка диплому для роботи/навчання
   🔗 https://www.nuffic.nl
2. **IDW** — для медичних та юридичних спеціальностей

**Що принести:**
- Оригінал диплому
- Академічна довідка (додаток до диплому)
- Переклад на нідерландську або англійську (присяжний перекладач)

**Строк розгляду:** 4–8 тижнів

## 📌 Студентська позика (DUO)

Якщо навчаєшся в акредитованому закладі в Нідерландах — можеш мати право на студентську позику через DUO.
🔗 https://www.duo.nl

Потрібно: DigiD + бути зареєстрованим студентом.
