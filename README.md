## How this workspace is organized

- Each project folder is **independent** — context does not mix between projects.
- Every project has a `CLAUDE.md` file inside it with its own context for Claude.
- Shared assets or cross-project notes go here in the root, not inside project folders.

## Adding a new project

1. Create a new folder here (e.g. `MyNewProject/`)
2. Inside it, create a `CLAUDE.md` with the project context
3. Add a row to the table above
